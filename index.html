About The Project

Smart Spending Manager is a Java-based desktop application designed to record and review personal expense information. It helps users organise their daily expenses and understand their spending habits.


The application uses Java Swing for its graphical user interface and CSV/Text files for storing expense details. It provides separate Transactions and Analytics sections.

Project Objectives

Easy Management

To organise personal expense information easily.

GUI Design

To develop a user-friendly interface using Java Swing.

Data Storage

To store expense information using CSV/Text files.

Expense Analysis

To provide a separate area for reviewing expenses.

Project Modules

🖥️ GUI Module

Provides a graphical interface using Java Swing.

🧾 Transactions Module

Provides access to expense transaction information.

📊 Analytics Module

Provides a separate area to review expense information.

📁 File Storage Module

Stores application data using CSV/Text files.
